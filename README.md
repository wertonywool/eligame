# eligame - El Gran Escape de Elizabeth

Juego de plataformas retro 2D desarrollado en HTML5 Canvas y Web Audio API.

## Caracteristicas
- 4 Mundos completos con multiples fases y desafios:
  - Mundo 1: El Jardin de la Emperatriz
  - Mundo 2: La Costa Marina y el Kraken
  - Mundo 3: La Ciudadela del Rascacielos
  - Mundo 4: El Monte Everest y el Firmamento Cosmico
- Batallas de jefes unicas: Kraken de las Profundidades, Gran Yeti de Cristal y Dragon Astral de Polaris.
- Mecanicas especiales: Baja gravedad cosmica, cavado en nieve, pico de hielo y pistola de portales dimensional.
- Selector de fases dinamico en el mapa de mundos.

## Como jugar localmente
1. Clona el repositorio:
   ```bash
   git clone https://github.com/wertonywool/eligame.git
   ```
2. Inicia el servidor:
   ```bash
   npm start
   ```
   (o abre `index.html` directamente en tu navegador web).
3. Visita:
   ```
   http://localhost:3000
   ```
